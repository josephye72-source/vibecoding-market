# 习惯方格：二创任务

## 轻改

Prompt 1:

```text
把习惯方格改成喝水记录器。保留日期切换、月度次数、连续天数反馈和 localStorage 持久化。
```

预期输出：

- 文案变成喝水场景。
- 日期方格的行为保持不变。

验收方式：

- 勾选某一天。
- 刷新后勾选状态仍然保留。

## 中改

Prompt 2:

```text
给已勾选日期增加可选备注。日期可以没有备注也保持勾选；如果填写备注，备注需要刷新后仍然存在。
```

预期输出：

- 有备注输入或小编辑器。
- 数据结构可以按日期保存备注。

验收方式：

- 给一个日期添加备注。
- 刷新后还能看到备注。

## 深改

Prompt 3:

```text
支持多个习惯。按习惯名称分别保存已勾选日期，并增加一个选择器切换当前习惯。
```

预期输出：

- 有习惯选择器。
- 每个习惯有独立数据。
- 当前习惯继续使用同一套月度次数和连续天数计算。

验收方式：

- 在习惯 A 勾选一天。
- 切换到习惯 B。
- 习惯 B 一开始没有习惯 A 的勾选状态。
