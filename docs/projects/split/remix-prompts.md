# 分账控制台：二创任务

## 轻改

Prompt 1:

```text
把分账控制台改成披萨分账计算器。保留总额/明细、参与者、即时结果、无效输入提示和复制摘要行为。
```

预期输出：

- 文案变成披萨场景。
- 分账计算规则保持不变。

验收方式：

- 输入总额和参与者。
- 人均金额立即更新。

## 中改

Prompt 2:

```text
增加一个小费百分比输入框。应用应该先计算总额加小费，再分摊给参与者，并把小费百分比写进摘要。
```

预期输出：

- 有小费输入框。
- 总额会加上小费。
- 摘要会说明小费比例。

验收方式：

- 输入 100、20% 小费、3 个人。
- 每人结果是 40。

## 深改

Prompt 3:

```text
增加按权重分账。某个参与者可以是 2 份，其他人是 1 份；页面要显示每个参与者各自需要支付多少。
```

预期输出：

- 参与者行可以填写权重。
- 结果区显示每个人的金额。
- 权重必须是正数，错误时给出提示。

验收方式：

- 一个 2x 参与者支付金额是 1x 参与者的两倍。
