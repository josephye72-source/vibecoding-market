但当前仍有 1 个 P2 问题，建议在公开发社媒或截图传播前修掉。

## 3. 发现的问题

### P2：首页“项目地图会继续长出来”模块没有跟随主内容容器

位置：

- `src/components/HomePage.ts` 中的 `.map-intent` 区块
- `src/styles/app.css` 中主页面容器样式未包含 `.map-intent`

现象：

- 桌面截图中，“项目地图会继续长出来”模块贴到视口最左侧。
- 移动端截图中，该模块同样没有左右内边距，视觉上和上方项目卡、复现路径、反馈入口不在同一个页面网格里。

影响：

- 不影响功能和文本理解。
- 但会削弱 V1 “高完成度、可持续扩展项目地图”的页面质感。
- 如果直接作为首发截图对外传播，会显得这个长期愿景模块是后来临时拼上去的。

建议：

- 将 `.map-intent` 加入首页主容器规则，和 `.hero`、`.projects`、`.path`、`.feedback` 使用同样的 `max-width` 与左右 padding。
- 或在 `.map-intent` 内部增加统一容器，让标题和正文与其他模块左边界一致。

该问题不构成 Gate 6 P1 阻塞，但建议作为发布前视觉修复项处理。

## 6. 剩余风险

这些不是 Gate 6 阻塞，但需要在后续版本规划中继续跟踪：

- 当前源码入口是静态源码索引，不是公开 GitHub 仓库 URL。V1 可以验收，但正式公开开源时仍需要仓库策略。
- 反馈入口目前是 pending 状态。Gate 7 不能只看按钮，需要真实反馈渠道和真实反馈数据。
- 英文版 UI 可用，但项目学习文档仍是中文优先，不应视为完整英文学习路径。
- 进入 V2 前，仍应满足真实反馈条件：至少 5 条有效外部反馈，或至少 2 次小白复现观察。
